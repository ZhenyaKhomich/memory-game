# 🧠 Memory Game

**Memory Game** — это игра на развитие памяти. На экране отображается набор карточек, перевернутых рубашкой вверх. Игрок кликает по карточкам, чтобы открыть их и найти пары одинаковых изображений.  
**Цель игры** — открыть все карточки за минимальное количество ходов.

---

## ✅ Описание проекта

- Набор из **девяти пар карточек**.
- Карточки отображаются **рубашкой вверх**.
- При клике:
    - Первая карточка переворачивается.
    - Вторая карточка открывается для проверки совпадения.
- Если изображения **совпадают** — карточки остаются открытыми.
- Если изображения **разные** — обе карточки снова переворачиваются рубашкой вверх.
- Игра завершается, когда **все карточки открыты** или **закончились шаги**.

---

## 🔍 Функционал

✔️ Ввод имени (создание логина) при входе, если пользователь не авторизован.  
✔️ Переворачивание карточек при клике.  
✔️ Проверка на совпадение пары.  
✔️ Игра завершается, когда все карточки открыты или закончились шаги.  
✔️ Возможность начать игру заново.  
✔️ После завершения выводится:
- **Результат** — количество ходов.  
  ✔️ Сохранение результатов последних **10 игр в localStorage**.  
  ✔️ Таблица рекордов с отображением предыдущих результатов.  
  ✔️ Плавная анимация переворота карточек.  
  ✔️ Возможность кастомного дизайна и улучшений.
